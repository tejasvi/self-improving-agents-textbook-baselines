I rewrote the agent for competitive programming problems and fixed several bugs that could make it stop silently. None of this has been run or tested.

**Bugs fixed in `llm_withtools.py` (the main correctness wins)**
- **Several tool calls in one reply:** Claude often requests more than one tool at a time. Previously only the first got a result, so the next API call failed, the error was swallowed, and the agent quit. All requested tools are now run and answered.
- **Unbounded loop:** the tool loop had no limit. It is now capped at 70 iterations.
- **Long tool output:** results are cut to about 12k characters, so the context doesn't overflow.
- **Cut-off replies:** if a reply hits the output token limit, the agent is told to continue instead of stopping.
- **Logging:** tool calls, results and errors are now written to the chat history.

**Tools**
- **`bash`:** now uses `subprocess` with a real timeout that kills stuck processes, cuts long output to its start and end, and reports nonzero exit codes. `BashSession` is kept because the existing tests import it.
- **`editor`:** adds `str_replace` for targeted edits and `view_range` for partial viewing. It still supports `view`, `create` and `edit`, so the existing tests should still pass.
- **New `run_python`:** runs a Python file with given input and a timeout. It reports output, stderr, exit code and runtime, and compares against expected output.
- **New `stress_test`:** runs a generator, a brute-force solution and the real solution with random seeds, and reports the first mismatching input, crash or timeout.

**Workflow in `forward()`**
- **Main pass:** a detailed prompt walks the agent through the problem:
  - find the target file;
  - work out the algorithm and check its complexity;
  - write the solution into the repo;
  - test the samples, then stress test and time the worst case.
  - It includes Python speed tips and rules for `Solution`-class tasks.
- **Retry:** if no edits were made, the main pass runs once more.
- **Review pass:** a fresh session with the current diff re-checks and stress-tests the solution and fixes problems. Scratch files are kept in `/tmp` so they don't end up in the patch.

# Thread-local storage for logger instances
thread_local = threading.local()

def get_thread_logger():
    return getattr(thread_local, 'logger', None)

def set_thread_logger(logger):
    thread_local.logger = logger

def setup_logger(log_file='./chat_history.md', level=logging.INFO):
    logger = logging.getLogger(f'AgenticSystem-{threading.get_ident()}')
    logger.setLevel(level)
    logger.handlers = []
    file_formatter = logging.Formatter('%(message)s')
    os.makedirs(os.path.dirname(log_file) or '.', exist_ok=True)
    file_handler = RotatingFileHandler(log_file, maxBytes=10*1024*1024, backupCount=5)
    file_handler.setLevel(level)
    file_handler.setFormatter(file_formatter)
    logger.addHandler(file_handler)
    set_thread_logger(logger)
    return logger

def safe_log(message, level=logging.INFO):
    logger = get_thread_logger()
    if logger:
        logger.log(level, message)
    else:
        print(f"Warning: No logger found for thread {threading.get_ident()}")


GUIDELINES = """
<guidelines>
## Workflow (follow these steps)
1. **Explore**: List the repository directory and view the existing files to find where the solution must go (e.g. an existing stub file, a `Solution` class, or a file that should contain a complete stdin/stdout program). Keep the existing file name, function/class names and signatures exactly.
2. **Understand**: Re-read the problem statement carefully. Note the exact input/output format, all constraints (sizes, value ranges), and corner cases (n = 1, empty, equal values, negative numbers, very large values, modulo requirements, multiple test cases, etc.). Work through the provided examples by hand to confirm your understanding.
3. **Design**: Derive an algorithm whose complexity fits the constraints (assume roughly 10^7 simple Python operations per second). Think about the correct approach before coding: greedy (prove it!), DP, binary search, graphs, number theory, data structures, etc. If unsure about a greedy, verify it against brute force.
4. **Implement**: Write the solution into the correct file in the repository using the editor tool.
5. **Test the examples**: Use the `run_python` tool (or bash) to run the solution on every sample from the statement and compare with the expected output. For a `Solution` class, write a small harness script in /tmp that imports/copies the class and calls the method on the examples.
6. **Stress test**: Write a simple, obviously-correct brute-force solution and a random small-test generator (taking a seed as argv[1]) in /tmp, then use the `stress_test` tool to compare them against your solution on hundreds of random tests. Fix every mismatch you find (the tool shows the failing input).
7. **Performance test**: Generate a maximum-size (worst-case) input and run your solution with a timeout to make sure it runs fast enough (ideally well under ~2 seconds). Optimize if it is too slow.
8. **Finalize**: Make sure the final solution in the repository is the tested version, and that it contains no debug prints.

## Python tips for competitive programming
- For stdin programs read input fast: `import sys; data = sys.stdin.buffer.read().split()` and parse tokens with an index; write output with `sys.stdout.write("\\n".join(...))`.
- Avoid deep recursion (Python's default limit is 1000). Prefer iterative DFS/BFS or explicit stacks. If recursion is unavoidable, raise the recursion limit and run in a thread with a large stack size.
- Prefer local variables inside a `main()` function, list comprehensions, built-ins (sorted, sum, min, max), `heapq`, `bisect`, `collections.deque/Counter/defaultdict`, `itertools`, `functools.lru_cache` (careful with depth).
- Watch out for answers requiring modulo (e.g. 10^9+7) and for exact output formatting (spaces, newlines, precision for floats, "YES"/"Yes" casing).
- For `Solution` class problems: do NOT read stdin or print; just implement the method. Include needed imports (e.g. `from typing import List, Optional`) at the top of the file, and keep any provided helper class definitions (e.g. ListNode, TreeNode) as the stub expects.

## Rules
- Put scratch files (brute force, generators, harnesses, test inputs) in /tmp, NOT in the repository. Only the solution file(s) in the repository should be changed.
- Use absolute paths. Each bash call runs in a fresh shell (cd does not persist).
- Do not stop until the solution passes the examples and the stress tests.
</guidelines>
"""


class AgenticSystem:
    def __init__(
            self,
            problem_statement,
            git_tempdir,
            base_commit,
            chat_history_file='./chat_history.md',
            test_description=None,
            self_improve=False,
            language='python'
        ):
        self.problem_statement = problem_statement
        self.git_tempdir = git_tempdir
        self.base_commit = base_commit
        self.chat_history_file = chat_history_file
        self.test_description = test_description
        self.self_improve = self_improve
        self.language = language

        self.code_model = CLAUDE_MODEL if not self_improve else OPENAI_MODEL

        self.logger = setup_logger(chat_history_file)

        with open(chat_history_file, 'w') as f:
            f.write('')

    def get_current_edits(self):
        diff = str(diff_versus_commit(self.git_tempdir, self.base_commit))
        new_msg_history = [
            {
                "role": "user",
                "content": [
                    {
                        "type": "text",
                        "text": f"# Current Repo Edits\n{diff}",
                    }
                ],
            }
        ]
        return new_msg_history

    def _current_diff(self):
        try:
            return str(diff_versus_commit(self.git_tempdir, self.base_commit))
        except Exception as e:
            safe_log(f"Error getting diff: {e}")
            return ""

    def forward(self):
        """
        The forward function for the AgenticSystem.
        """
        test_info = ""
        if self.test_description:
            test_info = f"\n<test_description>\n{self.test_description}\n</test_description>\n"

        task = f"""I have uploaded a code repository in the directory {self.git_tempdir}. It contains a competitive programming task to be solved in Python.

<problem_description>
{self.problem_statement}
</problem_description>
{test_info}
Your task is to write a correct and efficient solution by making changes to the files in the {self.git_tempdir} directory. The solution is either a complete program reading standard input and writing standard output, or a method of a given `Solution` class (check the existing files and the problem statement to decide). Hidden tests will check correctness on many cases, including large worst-case inputs, so both correctness and speed matter.
"""
        instruction = f"{task}\n{GUIDELINES}\nStart by exploring {self.git_tempdir}, then follow the workflow step by step."

        try:
            chat_with_agent(instruction, model=self.code_model, msg_history=[], logging=safe_log)
        except Exception as e:
            safe_log(f"Main pass error: {e}")

        # If nothing was written, try once more.
        if not self._current_diff().strip():
            safe_log("No edits after first pass; retrying.")
            try:
                chat_with_agent(instruction + "\n\nIMPORTANT: A previous attempt ended without writing any solution to the repository. Make sure to write the solution file.",
                                model=self.code_model, msg_history=[], logging=safe_log)
            except Exception as e:
                safe_log(f"Retry pass error: {e}")

        # Review / verification pass with fresh context.
        diff = self._current_diff()
        if diff.strip():
            review = f"""{task}
A previous attempt produced the following changes to the repository (git diff versus the original):

<current_edits>
{diff[:30000]}
</current_edits>
{GUIDELINES}
Your job now is to act as a rigorous reviewer and fixer:
1. View the current solution file(s) in {self.git_tempdir}. Re-read the problem statement and check the solution logic against it, especially the input/output format, edge cases and constraints.
2. Run the solution on all examples from the statement.
3. Write an independent brute-force solution and random generator in /tmp and run the `stress_test` tool with many small random tests (include edge cases such as minimum sizes).
4. Run a worst-case maximum-size input to check the running time.
5. If anything fails or is too slow, fix the solution in the repository (or rewrite it with a better algorithm) and re-test. If everything passes, leave it as is.
Remove any scratch files you may have created inside the repository; keep only the solution."""
            try:
                chat_with_agent(review, model=self.code_model, msg_history=[], logging=safe_log)
            except Exception as e:
                safe_log(f"Review pass error: {e}")


def main():
    parser = argparse.ArgumentParser(description='Process repository with an agentic system.')
    parser.add_argument('--problem_statement', required=True, help='The problem statement to process')
    parser.add_argument('--git_dir', required=True, help='Path to git repository directory')

    parser.add_argument('--language', required=False, default="python", choices=['cpp', 'java', 'python', 'go', 'rust', 'javascript'], help='Task\'s programming language')
    args = parser.parse_args()

    agentic_system = AgenticSystem(

        git_tempdir=args.git_dir,

        self_improve=args.self_improve,

    model_patch_outfile = os.path.join(args.outdir, 'model_patch.diff') if args.outdir else 'model_patch.diff'

if __name__ == "__main__":
    main()

import ast

import backoff
import openai
import copy

CLAUDE_MODEL = 'claude-3-5-sonnet-20241022'
OPENAI_MODEL = 'claude-3-5-sonnet-20241022'

MAX_TOOL_ITERATIONS = 70
MAX_TOOL_RESULT_CHARS = 12000


def truncate_result(text, limit=MAX_TOOL_RESULT_CHARS):
    text = "" if text is None else str(text)
    if len(text) <= limit:
        return text
    half = limit // 2
    return text[:half] + f"\n... <{len(text) - limit} characters truncated> ...\n" + text[-half:]


def process_tool_call(tools_dict, tool_name, tool_input):
    try:
        if tool_name in tools_dict:
            return tools_dict[tool_name]['function'](**tool_input)
        else:
            return f"Error: Tool '{tool_name}' not found"
    except Exception as e:
        return f"Error executing tool '{tool_name}': {str(e)}"

@backoff.on_exception(
    backoff.expo,
    (openai.RateLimitError, openai.APITimeoutError, anthropic.RateLimitError, anthropic.APIStatusError),
    max_time=600,
    max_value=60,
)
def get_response_withtools(
    client, model, messages, tools, tool_choice,
    logging=None, max_retry=3
):
    try:
        if 'claude' in model:
            response = client.messages.create(
                model=model,
                messages=messages,
                max_tokens=4096,
                tool_choice=tool_choice,
                tools=tools,
            )
        elif model.startswith('o3-'):
            response = client.responses.create(
                model=model,
                input=messages,
                tool_choice=tool_choice,
                tools=tools,
                parallel_tool_calls=False
            )
        else:
            raise ValueError(f"Unsupported model: {model}")
        return response
    except Exception as e:
        if logging:
            logging(f"Error in get_response_withtools: {str(e)}")
        if 'Input is too long' in str(e) or 'prompt is too long' in str(e):
            raise
        if max_retry > 0:
            return get_response_withtools(client, model, messages, tools, tool_choice, logging, max_retry - 1)
        raise

def check_for_tool_use(response, model=''):
    """
    Checks if the response contains a tool call.
    """
    if 'claude' in model:
        if response.stop_reason == "tool_use":
            tool_use_block = next(block for block in response.content if block.type == "tool_use")
            return {
                'tool_id': tool_use_block.id,
                'tool_name': tool_use_block.name,
                'tool_input': tool_use_block.input,
            }

    elif model.startswith('o3-'):
        tool_call = None
        for item in response.output:
            if item.type == "function_call":
                tool_call = item
                break

        if tool_call:
            return {
                'tool_id': tool_call.call_id,
                'tool_name': tool_call.name,
                'tool_input': json.loads(tool_call.arguments),
            }

    else:
        pattern = r'<tool_use>(.*?)</tool_use>'
        match = re.search(pattern, response, re.DOTALL)
        if match:
            tool_use_str = match.group(1).strip()
            try:
                tool_use_dict = ast.literal_eval(tool_use_str)
                if isinstance(tool_use_dict, dict) and 'tool_name' in tool_use_dict and 'tool_input' in tool_use_dict:
                    return tool_use_dict
            except Exception:
                pass

    return None

def convert_tool_info(tool_info, model=None):
    """
    Converts tool_info from Claude format to the given model's format.
    """
    if 'claude' in model:
        return {
            'name': tool_info['name'],
            'description': tool_info['description'],
            'input_schema': tool_info['input_schema'],
        }
    elif model.startswith('o3-'):
        def add_additional_properties(d):
            if isinstance(d, dict):
                if 'properties' in d:
                    d['additionalProperties'] = False
                for k, v in d.items():
                    add_additional_properties(v)
        add_additional_properties(tool_info['input_schema'])
        for p in tool_info['input_schema']['properties'].keys():
            if not p in tool_info['input_schema']['required']:
                tool_info['input_schema']['required'].append(p)
                t = copy.deepcopy(tool_info['input_schema']['properties'][p]["type"])
                if isinstance(t, str):
                    tool_info['input_schema']['properties'][p]["type"] = [t, "null"]
                elif isinstance(t, list):
                    tool_info['input_schema']['properties'][p]["type"] = t + ["null"]

        return {
            'type': 'function',
            'name': tool_info['name'],
            'description': tool_info['description'],
            'parameters': tool_info['input_schema'],
            "strict": True,
        }
    else:
        return tool_info

def convert_block_claude(block):
    if isinstance(block, dict):
        block_type = block.get('type')
        text = block.get('text')
        tool_name = block.get('name')
        tool_input = block.get('input')
        tool_result = block.get('content')
    else:
        block_type = getattr(block, 'type', None)
        text = getattr(block, 'text', None)
        tool_name = getattr(block, 'name', None)
        tool_input = getattr(block, 'input', None)
        tool_result = getattr(block, 'content', None)

    text = text or ""

    if block_type == "text":
        return {"type": "text", "text": text}
    elif block_type == "tool_use":
        return {
            "type": "text",
            "text": f"<tool_use>\n{{'tool_name': {tool_name}, 'tool_input': {tool_input}}}\n</tool_use>"
        }
    elif block_type == "tool_result":
        return {"type": "text", "text": f"Tool Result: {tool_result}"}
    else:
        return {"type": "text", "text": str(block)}

def convert_msg_history_claude(msg_history):
    new_msg_history = []
    for msg in msg_history:
        role = msg.get('role', '')
        content_blocks = msg.get('content', [])
        if isinstance(content_blocks, str):
            content_blocks = [{"type": "text", "text": content_blocks}]
        new_content = []
        for block in content_blocks:
            new_content.append(convert_block_claude(block))
        new_msg_history.append({"role": role, "content": new_content})
    return new_msg_history

def convert_msg_history_openai(msg_history):
    new_msg_history = []
    for msg in msg_history:
        if isinstance(msg, dict):
            role = msg.get('role', '')
            content = msg.get('content', '')
            if role == 'tool':
                new_msg = {
                    "role": "user",
                    "content": [{"type": "text", "text": f"Tool Result: {content}"}],
                }
            else:
                new_msg = {"role": role, "content": content}
        else:
            role = getattr(msg, 'role', None)
            content = getattr(msg, 'content', None)
            tool_calls = getattr(msg, 'tool_calls', None)
            if tool_calls:
                tool_call = tool_calls[0]
                function_name = getattr(tool_call.function, 'name', '')
                function_args = getattr(tool_call.function, 'arguments', '')
                new_msg = {
                    "role": role,
                    "content": [{
                        "type": "text",
                        "text": f"<tool_use>\n{{'tool_name': {function_name}, 'tool_input': {function_args}}}\n</tool_use>",
                    }],
                }
            else:
                new_msg = {"role": role, "content": [{"type": "text", "text": content}]}
        new_msg_history.append(new_msg)
    return new_msg_history

def convert_msg_history(msg_history, model=None):
    if 'claude' in model:
        return convert_msg_history_claude(msg_history)
    elif model.startswith('o3-'):
        return convert_msg_history_openai(msg_history)
    else:
        return msg_history

def chat_with_agent_manualtools(msg, model, msg_history=None, logging=print):
    if msg_history is None:
        msg_history = []
    system_message = f'You are a coding agent.\n\n{get_tooluse_prompt()}'
    new_msg_history = msg_history

    try:
        all_tools = load_all_tools(logging=logging)
        tools_dict = {tool['info']['name']: tool for tool in all_tools}
        client, client_model = create_client(model)

        logging(f"Input: {msg}")
        response, new_msg_history = get_response_from_llm(
            msg=msg,
            client=client,
            model=client_model,
            system_message=system_message,
            print_debug=False,
            msg_history=new_msg_history,
        )
        logging(f"Output: {response}")

        tool_use = check_for_tool_use(response, model=client_model)
        for _ in range(MAX_TOOL_ITERATIONS):
            if not tool_use:
                break
            tool_name = tool_use['tool_name']
            tool_input = tool_use['tool_input']
            tool_result = truncate_result(process_tool_call(tools_dict, tool_name, tool_input))

            tool_msg = f'Tool Used: {tool_name}\nTool Input: {tool_input}\nTool Result: {tool_result}'
            logging(tool_msg)
            response, new_msg_history = get_response_from_llm(
                msg=tool_msg,
                client=client,
                model=client_model,
                system_message=system_message,
                print_debug=False,
                msg_history=new_msg_history,
            )
            logging(f"Output: {response}")
            tool_use = check_for_tool_use(response, model=client_model)

    except Exception as e:
        logging(f"Error in chat_with_agent_manualtools: {e}")

    return new_msg_history

def chat_with_agent_claude(
        msg,
        model='bedrock/us.anthropic.claude-3-5-sonnet-20241022-v2:0',
        msg_history=None,
        logging=print,
    ):
    if msg_history is None:
        msg_history = []
    new_msg_history = [
        {
            "role": "user",
            "content": [{"type": "text", "text": msg}],
        }
    ]
    separator = '=' * 10
    logging(f"\n{separator} User Instruction {separator}\n{msg}")

    try:
        client, client_model = create_client(model)

        all_tools = load_all_tools(logging=logging)
        tools_dict = {tool['info']['name']: tool for tool in all_tools}
        tools = [convert_tool_info(tool['info'], model=client_model) for tool in all_tools]

        response = get_response_withtools(
            client=client,
            model=client_model,
            messages=msg_history + new_msg_history,
            tool_choice={"type": "auto"},
            tools=tools,
            logging=logging,
        )

        for iteration in range(MAX_TOOL_ITERATIONS):
            # Log text blocks
            for block in response.content:
                if getattr(block, 'type', None) == 'text' and block.text:
                    logging(f"\n{separator} Agent {separator}\n{block.text}")

            tool_blocks = [b for b in response.content if getattr(b, 'type', None) == 'tool_use']

            if response.stop_reason == "tool_use" and tool_blocks:
                new_msg_history.append({"role": "assistant", "content": response.content})
                results = []
                for b in tool_blocks:
                    tool_input = b.input if isinstance(b.input, dict) else {}
                    logging(f"\n{separator} Tool Call: {b.name} {separator}\n{tool_input}")
                    tool_result = truncate_result(process_tool_call(tools_dict, b.name, tool_input))
                    if not tool_result:
                        tool_result = "(no output)"
                    logging(f"\n{separator} Tool Result {separator}\n{tool_result}")
                    results.append({
                        "type": "tool_result",
                        "tool_use_id": b.id,
                        "content": tool_result,
                    })
                remaining = MAX_TOOL_ITERATIONS - iteration - 1
                if remaining == 10:
                    results.append({
                        "type": "text",
                        "text": "Note: you are running low on remaining tool calls (about 10 left). Make sure the final tested solution is saved in the repository.",
                    })
                new_msg_history.append({"role": "user", "content": results})
            elif response.stop_reason == "max_tokens":
                text_blocks = [{"type": "text", "text": b.text} for b in response.content
                               if getattr(b, 'type', None) == 'text' and b.text]
                if not text_blocks:
                    text_blocks = [{"type": "text", "text": "(response truncated)"}]
                new_msg_history.append({"role": "assistant", "content": text_blocks})
                new_msg_history.append({
                    "role": "user",

class BashSession:
    """A session of a bash shell (kept for backward compatibility)."""
    def __init__(self):
        self._started = False
        self._process = None
        self._timed_out = False
        self._timeout = 120.0
        self._sentinel = "<<exit>>"
        self._output_delay = 0.2

    async def start(self):
        if self._started:
            return
        self._process = await asyncio.create_subprocess_shell(
            "/bin/bash",
            preexec_fn=os.setsid,
            stdin=asyncio.subprocess.PIPE,
            stdout=asyncio.subprocess.PIPE,
            stderr=asyncio.subprocess.PIPE,
            env=os.environ.copy()
        )
        self._started = True

    def stop(self):
        if not self._started:
            return
        if self._process.returncode is None:
            self._process.terminate()
        self._process = None
        self._started = False

    async def run(self, command):
        if not self._started:
            raise ValueError("Session has not started.")
        out, err = await asyncio.wait_for(
            self._process.communicate(command.encode()), timeout=self._timeout
        )
        self._started = False
        return out.decode(errors='replace').strip(), err.decode(errors='replace').strip()


def _truncate(text, limit=MAX_OUTPUT_CHARS):
    if len(text) <= limit:
        return text
    half = limit // 2
    return text[:half] + f"\n... <{len(text) - limit} characters truncated> ...\n" + text[-half:]
